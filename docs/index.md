# Hello World App

A minimal, tested Python Hello World CLI packaged for multiple platforms with GitHub Actions.

Docs home: https://bigbatmanorg.github.io/hello-world-app

- **CLI:** `hello-world-app [name]`
- **Package:** built as a wheel on Linux.
- **Executables:** PyInstaller one-file binaries for Linux and Windows.
- **Docs:** MkDocs site auto-published to GitHub Pages.

Use this repository as a template for small utilities that need simple distribution across platforms.
